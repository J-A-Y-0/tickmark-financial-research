# Internal knowledge base (synthetic)

These documents stand in for a research team's internal notes at **Harbor Point Capital**,
a fictional investment firm. Every document, person, price target, estimate and deal in
this folder is invented for the demo. Figures attributed to company filings match the
10-K excerpts in `data/filings/`; everything labelled as a house view or estimate is
fictional and is not investment advice.

Each file starts with JSON front matter. `allowed_roles` controls which roles can
retrieve the document; the deal memo is restricted to portfolio managers so the access
model can be demonstrated and tested.
